# Contributing

Thanks for helping improve Shortlist.

- Keep it dependency-free: HTML, CSS and vanilla JavaScript in `index.html`.
- Scoring must stay deterministic and explained on the page.
- Open an issue before large changes. Small fixes can go straight to a pull request.
- Test by opening `index.html`, clicking **Load sample data** and **Analyze match**.
- Good first issues: add skills to the `SKILLS` list, add stop words, improve suggestions.
